# MG-RESTAURANT
🧑‍💻 Full Stack Web Development Project – Reestar
🍽️ Overview

Reestar is a full-stack food ordering web application that allows users to browse dishes, view details, and place orders online.
The project demonstrates the core skills of a full-stack developer — combining frontend, backend, and database technologies to create a complete web solution.

🚀 Features

🍔 Interactive and responsive food menu

🧾 Order placement form with data validation

📬 Contact section for user inquiries

🏗️ Tech Stack
Layer	Technology
Frontend	HTML5, CSS3, JavaScript,
Deployment	GitHub Pages 
Tools	VS Code.

🧠 Learning Highlights

This project helped me practice:

Designing responsive UI using HTML and CSS

Building REST APIs with Node.js and Express

Connecting backend with MongoDB for data persistence

Version controlling with Git and GitHub

Deploying full-stack apps to live servers
